펜을 끄지 않고 넘기기

  • 툴바의 ◀ ▶, 키보드 → ←, 프레젠터 리모컨은 펜 상태에서도 넘깁니다.
  • 장을 넘겨도 펜은 그대로이고, 돌아오면 판서가 남아 있습니다.

여기에 자유롭게 써 보세요.

버튼은 톡, 판서는 쭉

펜 상태에서 버튼을 톡 누르면 버튼이 눌리고, 버튼 위에서 끌면 판서가 됩니다.

칠판 모드

  • 툴바의 「칠판」을 누르면 빈 칠판이 열리고, 같은 자리 버튼이 「슬라이드」로 바뀝니다.
  • 칠판은 여러 장 만들 수 있고, 바탕(흰색·모눈·줄·초록 칠판·좌표평면)을 고를 수 있습니다.
  • 반을 바꾸면 그 반의 판서와 칠판이 나옵니다.

확인해 볼 것

  1. 펜 → ▶ → 쓰기 → ◀ : 앞 장 판서가 남아 있나요?
  2. 반 메뉴에서 「2반」 추가 → 판서가 비었나요? 「기본」으로 돌아가면 판서가 다시 나오나요?
  3. 창을 닫았다 다시 열어도 판서가 남아 있나요?
  4. Ctrl+P → 인쇄 미리보기에 모든 장이 단계를 펼친 채로 나오나요?
