# v1.6.0 현황 (2026-10-15)

연수에서 받은 수업 HTML 가운데 같은 삼투 PPT를 ChatGPT와 클로드로 만든 두 파일을 견주었다. ChatGPT판은 엔진의 입자 상자, 계산 상자, 그래프를 하나도 쓰지 않고 그림을 직접 그렸다. 슬라이더를 밀면 그림이 한 번에 바뀔 뿐 움직이는 것이 없었다. 클로드판은 입자 상자를 쓰고 빨대 속 물이 차오르는 움직임을 넣었다.

모델 성향만의 문제가 아니었다. 지침의 익스플로라그램 정의에 움직임이 없었다. 지침은 "부품에 개념을 맞추지 말고 직접 짠다"고 권했고 뼈대 예시도 직접 짠 스크립트였다. v1.6은 움직임을 엔진 기본값으로 옮기고 지침을 '부품 먼저'로 바꾼다. 선생님 파일은 저장소에 넣지 않는다.

## 엔진

- **계산 상자가 그림을 흘려 보낸다**(`58-calc.js`). 사람이 손잡이를 움직이면 수(`data-expr`), 막대, `data-attr`, `data-style` 값이 0.6초 동안 끝값으로 간다.
  - 끝값이 정수면 정수로 세어 간다. 수만 다른 글자 값(`rotate(…)`, `points`)도 흐르고 `#` 색은 바로 바뀐다.
  - 사람이 움직였는지는 바로 앞의 `isTrusted` 이벤트로 가린다. 그래서 점검, `states.mjs`, 시험, 수업 스크립트가 값을 바꾸면 바로 끝값이다. 보고 있지 않은 장과 ⚙ 「움직임 끄기」도 바로 끝값이다.
  - `data-tween="off"`, `data-tween="1.5"`(초), `<html data-tween="off">`로 조절한다. 막대의 CSS transition은 뺐다.
- **재생 `data-play`**(`72-play.js`, `90-play.css`). 슬라이더에 붙이면 「▶ 재생」과 「처음으로」 단추가 생기고 엔진이 시간을 흘린다. `data-loop`면 되풀이한다.
  - 값이 바뀔 때마다 `input` 이벤트를 보내므로 직접 짠 그림에도 쓸 수 있다. 계산 상자는 다음 칸까지 걸리는 시간 동안 그림을 흘려 보낸다.
  - 손으로 잡거나 장을 넘기면 멈춘다. 그래프 선에 `data-x="0, max(t, 0.01)"`을 주면 곡선이 시간을 따라 그려진다.
- **점검 경고 둘**(`42-audit.js`). 둘 다 경고라 툴바 「점검 N」에는 세지 않는다. 수업 스크립트와 CSS에 움직임(`requestAnimationFrame`, `setInterval`, `transition` 등)이 하나라도 있으면 알리지 않는다. 파일 안에 넣은 엔진 코드는 세지 않는다.
  - `static-model`: 엔진 부품 밖의 슬라이더나 고르기가 있는 장을 쪽 번호와 함께 한 줄로 알린다.
  - `use-part`: 그런 장에 직접 그린 점이 12개 이상이면 입자 상자를 권한다.
  - 둘 중 하나가 있으면 「AI에게 보낼 말 복사」의 지킬 것에 '부품을 먼저 쓰라'는 줄이 붙는다.
  - 점검은 흘러가는 중인 그림을 끝값으로 놓고 잰다(`Calc.settle`).
- 그래프 위 끌 수 있는 점(`data-drag`)도 이번 판에 들어 있다(커밋 2bb60ab). 끌기는 흘려 보내지 않는다.

## 지침

- SKILL.md: 부품을 먼저 찾고 없을 때만 직접 짠다. 인터뷰 ③은 부품 이름 대신 장면으로 묻고 AI가 두세 개를 골라 제안한다. 설계표에 '쓸 부품'과 '움직이는 것' 칸을 더했고 적은 것은 빼지 않고 만든다. 기준 1에 움직임을 넣었다.
- exploragram.md: 정의에 움직임, 설계 순서 5 「움직임과 부품을 정한다」, '장면 메뉴' 표(장면 → 부품 → 움직이는 것)를 더했다.
  - '엔진에 붙이는 뼈대'를 스크립트 없는 두 개로 바꿨다. 계산 상자 흡수력 모형과 재생 빨대 실험이다.
  - 직접 짠 예시는 '직접 짜야 할 때'로 옮기고 SVG `transition`을 넣었다.
- components.md: 8절에 움직임과 `data-tween`, 16절 재생, 점검 코드 `static-model`과 `use-part`를 더했다.
- 레퍼런스 `sci-diffusion.html` 5쪽 잉크 시간 막대에 `data-play="8"`과 입자 transition을 넣었다. 입자는 0초 자리에 미리 놓는다. 「재생」 줄이 들어갈 자리를 만들려고 범례를 가로로 놓고 억지 줄바꿈(`<br>&nbsp;`)을 뺐다.

## 확인

- 단위 63 통과, 브라우저 38파일 PASS. 새 시험 `parts-motion` 11개는 흘려 보내기, 바로 끝값이 되는 경우, 재생, 점검 경고를 본다.
- `run-docs` errors 0(빈 그림 자리 경고 1은 원래 있던 것). 레퍼런스 5개 오류 0, 경고 0.
- 삼투 파일 두 개를 새 엔진으로 열었다(scratchpad 사본).
  - ChatGPT판: `static-model`(직접 짠 4개 장)과 `use-part`(직접 그린 입자 74개).
  - 클로드판: 알림 없음. 처음에는 농도를 점으로 나타낸 세포 그림에 `use-part`가 떴다. 그래서 움직임이 있는 파일에서는 알리지 않게 좁혔다.
- 화면: 재생 뼈대(재생 중, 끝)와 레퍼런스 5쪽(재생 중)을 1280px, 768px, 375px에서 찍어 겹침과 넘침을 확인했다. 크롬에서 SVG `cx`가 transition으로 흐르는 것을 쟀다.
- 새 한국어 문장은 korean-humanize light 게이트를 거쳤다(변경률 0.2%, 연결어미 쉼표 줄임).
- 미확인: 전자칠판 실물, 파이어폭스에서 SVG 속성 transition, 웨일.
